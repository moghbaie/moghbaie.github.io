# moghbaie.github.io

Personal website of Mehrnoosh Oghbaie, live at <https://moghbaie.github.io>.

A plain HTML/CSS single page — no build step. GitHub Pages serves it directly
(`.nojekyll` turns off Jekyll processing).

| What | File |
|------|------|
| All page content | `index.html` |
| Colors, fonts, layout | `assets/css/style.css` (colors are variables at the top) |

To preview locally, open `index.html` in a browser. Push to `master` to publish.
